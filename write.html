Google sign-in is not configured yet.

It needs an OAuth client ID from the Google Cloud console, with this site listed as an authorised JavaScript origin. Put it in write.html as GOOGLE_CLIENT_ID and the button appears. Until then the passphrase is the way in.

What signing in does here, and what it does not.

Google's token is checked properly — the signature is verified against Google's own public keys, and the address inside it has to be yours. That part is real.

But this is a static page with no server, so all of that runs in the browser, and anyone determined can step over it by editing the page. The same is true of the passphrase. Treat either as a lock on a door, not a safe.

The protection that actually holds is elsewhere. Nothing here can reach the site on its own — publishing needs a write to the repository, and that needs a GitHub token that signing in does not give you. Someone past this gate would gain a text box and nothing else.
