What this passphrase does, and what it does not.

This is a static page with no server behind it, so the check runs in your browser and anyone determined can read past it. Treat it as a lock on a door, not a safe: it keeps the editor out of the way of passers-by.

The protection that actually matters is elsewhere. Nothing typed here can reach the site on its own — publishing needs a write to the repository, and only you can do that. Someone who bypassed this gate would gain a text box and nothing else.

Two ways. The first writes to the site for you; the second hands you the file and leaves the writing to you.

Straight to the site

Needs a GitHub token with permission to write to this one repository. It is kept in this tab only, never saved to the page and never sent anywhere but GitHub.

Take the file away

Downloads articles.json with this article added to whatever is already published. Drop it in the root of the gh-pages branch and commit.
